# MunichGameJam2026

## Beschreibung

Dieses Repo enthält das Unity Projekt des Games "Democratic Election Idle Tycoon", unserem Beitrag zur ersten Munich Game Jam (2026).

Das Spiel kombiniert Idle-Elemente mit Minigames und Quizfragen, durch die das Spiel einen "Serious" Aspekt erhält.
